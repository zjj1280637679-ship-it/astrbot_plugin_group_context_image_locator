# 群聊图片定位与原图转发

让你的 AI 在 AstrBot 原生群聊感知里看到图片描述与提取码，需要时再取回原图、查看细节或转发。插件不建立第二套聊天历史，也不要求安装图片生成或聊天记录搜索插件。

交流与反馈：**QQ 群 916646029**

## 你会得到什么

- 群聊中的图片先由 AstrBot 原生感知照常描述，再附上一枚 `ctximg:` 提取码。
- AI 只有确实要看图时才读取原图，普通文字回合不会承担图片负担。
- 一次最多按顺序处理多张图片；某一张失效不会阻断同批其他图片。
- 转发可选聊天图片或原文件：聊天图片可能被 QQ 压缩，原文件不压缩。
- 默认只在当前有效请求含提取码时暴露两个工具，减少无关工具上下文。

## 工作流与工具卡

群聊感知中会出现类似内容：

```text
[Image: 一张带文字的截图] [该图片提取码=ctximg:0123456789abcdef]
```

模型工具遵守以下紧凑契约：

```text
h ::= 16位十六进制
r ::= "ctximg:" + h | h
R ::= [r1,...,rn], 1 <= n <= N

resolve_context_images(R)
  -> 与 R 同序的读取结果；不向聊天发送

forward_context_images(R, d)
  d ::= "inline" | "original_file"
  -> 按 R 顺序真实发送到当前聊天
```

已知提取码并且只想转发时可以直接发送；需要先看图或按内容挑选时，先读取再发送。

## 安装与启用

1. 在 AstrBot 插件管理中使用仓库 URL 安装，或上传精简 ZIP。
2. 确认平台是 `aiocqhttp`，AstrBot 版本满足 `>=4.26.1`（不设版本上限）。
3. 在 AstrBot 配置中启用群聊上下文感知；只有 `group_icl_enable=true` 时插件才缓存群图和附加提取码。图片描述模型可选。
4. 保存插件配置并重载插件。

仓库地址：

```text
https://github.com/zjj1280637679-ship-it/astrbot_plugin_group_context_image_locator
```

## 你可以这样说

- “看看刚才那张带表格的图，告诉我第二列写了什么。”
- “把刚才那两张图按原文件转发回来。”
- “只转发那张蓝色背景的图。”

自然语言由 AstrBot 主 Agent 理解；插件只执行明确的提取码读取或发送，不猜测你的用途。

## 配置

| 配置项 | 默认值 | 作用 |
| --- | ---: | --- |
| `max_images_per_call` | `5` | 单次最多读取或发送的图片数，范围 1–20 |
| `max_capture_images_per_message` | `10` | 单条消息最多缓存并标记的图片数，范围 1–50 |
| `max_capture_image_mb` | `32` | 单张缓存与模型读取上限，范围 1–128 MiB |
| `only_expose_when_referenced` | `true` | 当前请求没有提取码时隐藏工具 |
| `retention_hours` | `168` | 定位记录与原图缓存保留小时数；0 表示不按时间清理 |
| `max_cache_mb` | `1024` | 本插件缓存空间上限；0 表示不按空间清理 |
| `cleanup_interval_seconds` | `3600` | 清理检查间隔，范围 60–86400 秒 |

## 边界、隐私与失败语义

- 插件使用 AstrBot 官方消息事件、LLM 请求和工具钩子，不需要修改 AstrBot 核心。
- 临时提取码标记在原生群聊感知记录前加入，并由低优先级清理器移除；若其他插件在两阶段之间强制终止事件，当前事件里的临时标记可能保留到该事件对象释放，但不会写入主对话历史。
- 原图只保存在本插件数据目录，插件没有独立上传后端，也不会写入插件源码目录。AI 调用读取工具时，原图会作为工具图片交给 AstrBot 当前配置的模型提供商处理。
- 未启用原生群聊感知时不缓存图片。单条消息图片数和单图大小在读入插件内存、写入缓存前受配置边界约束。
- 提取码按平台实例、机器人账号和群隔离，不能跨群读取。
- `inline` 是一次真实聊天图片发送；`original_file` 是一次真实文件发送。
- 缓存缺失、过期或下载失败会返回结构化 `unavailable`，不会伪造图片，也不会阻断同批可用项。
- 插件不会调用图片生成 API，不管理任何图片模型额度或次数。
- 真实转发统一使用 AstrBot 公共 `event.send` 路由；返回的 `message_id` 可能为空，但发送成败会如实报告。

## 独立性

本插件拥有自己的存储、提取码域和发送路径。它不导入、不调用、不共享其他图片、搜索或素材插件的内部状态。多插件同时安装时，只由主 Agent 分别调用各自公开工具。
